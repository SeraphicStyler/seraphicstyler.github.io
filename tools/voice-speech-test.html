Concierge speech check

The concierge does not read the interface aloud — it rewrites a house record into spoken sentences first (js/fd-voice.js → listingParts), then hands those to the engine. This page stubs speechSynthesis and prints the exact utterance queue: text, the voice language each part is routed to, and its rate. That is the whole contract, so a regression shows up here as words rather than as sound. Serve the site (node tools/serve.mjs) and open this file through the server, not from file://.
